# Checklist before making this repository public

- [ ] Confirm redistribution permissions for every included CSV (or remove CSVs and provide only source links).
- [ ] Review all datasets for personally identifying or restricted healthcare information.
- [ ] Verify that the original report can be publicly shared before uploading it.
- [ ] Inspect scripts and commit history for local paths, secrets, API keys, and personal information.
- [ ] Confirm that repository claims and RMSE results correspond to final project experiments.
- [ ] Clarify or rerun experiments with potential feature-selection/scaler leakage before claiming strong generalization.
- [ ] Test important scripts in a clean virtual environment; correct data paths and document reproducibility.
- [ ] Check repository ownership/academic or team attribution if collaborators contributed.

README results come from the supplied cross-account project summary, not from independent reruns.
